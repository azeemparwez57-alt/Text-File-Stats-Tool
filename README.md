# Text File Stats Tool

A Python project that reads a text file and analyzes its basic statistics using core Python concepts.

## Features

- Count total lines
- Count total words
- Count characters excluding whitespace
- Find the longest non-empty line
- Find the shortest non-empty line
- Identify the most frequently occurring word
- Handle missing files using exception handling

## Concepts Used

- File Handling
- Functions
- Loops and Conditional Statements
- Lists and Dictionaries
- String Methods
- Exception Handling

## How to Run

1. Clone or download this repository.
2. Open the project in JupyterLab.
3. Run the notebook cells.
4. Enter the name of the text file when prompted, for example `sample.txt`.
